Objective:
Migrate an existing browser-based compositing playground (“Aether”) from a JavaScript Canvas2D rendering core to a Rust rendering core compiled to WebAssembly, while keeping the current JS UI, layer editing code, and animation system. Rust produces an RGBA frame each tick; JS blits that frame into an HTML <canvas>.

0. Quick Checklist for the Agent
 Create Rust workspace with aether_core + aether_wasm.

 Define canonical data model: Comp → Layers (size, blend, opacity, params).

 Implement software (CPU) rasterizer in Rust for a subset of layers (Gradient + Image required; others stubbed).

 Implement basic blend (Normal alpha over) first; others TODO.

 Expose WASM bindings: create renderer, load comp (JSON), update live layer params, render frame -> raw RGBA pointer/len.

 JS: integrate WASM module; per frame: push current evaluated params from existing JS animation system → call Rust render → copy pixels → putImageData.

 Preserve current UI & dev ergonomics for coding new JS layers while gradually porting to Rust equivalents.

 Strictly avoid WebGPU, React refactors, ECS, Vulkan, or full video decode in this pass.

5.2 Coordinate & Pixel Conventions
Pixel format: RGBA8, non-premultiplied.

Memory layout: row-major, top-to-bottom, left-to-right.

Index: idx = ((y * width) + x) * 4.

Channels: R,G,B,A each 0–255.

5.3 Blend Modes (Phase 1)
Implement Normal alpha-over only.

Future placeholder enum variants: Add, Multiply, Screen, etc. but return early (no-op fallback) until implemented.

impl Comp {
    /// Render to supplied RGBA8 buffer; buffer length must be width*height*4.
    pub fn render(&self, t_ms: f32, out: &mut [u8]) {
        // clear
        fill_rgba(out, self.background);
        // render layers bottom->top
        for layer in &self.layers {
            if !layer.base.enabled { continue; }
            match &layer.kind {
                LayerKind::Gradient(p) => render_gradient(layer, p, out, self.width, self.height),
                LayerKind::Image(p)    => render_image(layer, p, out, self.width, self.height),
                // ...
            }
        }
    }
}
Note: t_ms is passed but ignored for Phase 1; JS pushes time-evaluated param states. Keep it for forward compatibility.

6. Rendering Algorithms (Phase 1 CPU)
6.1 Transform Sampling
For each destination pixel (x,y) in comp space:

Map to layer local via inverse transform.

Sample layer content (procedural or texture).

Blend sample pixel over existing out pixel using:

ini
Copy
Edit
out.rgb = src.rgb * src.a*opacity + dst.rgb * (1 - src.a*opacity)
out.a   = src.a*opacity + dst.a*(1 - src.a*opacity)
Use float 0..1 internal math; write back 0..255 u8.

Performance note: For Gradient, compute analytic formula instead of per-pixel transform inversion (precompute directional ramp). OK to start naïve loops; optimize later.

6.2 Layer Implementations (Min)
Gradient Layer

Linear gradient rotated by angle_deg.

Compute normalized projection along gradient axis; interpolate c0→c1.

Accept premult toggle? No; straight.

Image Layer

Pixels supplied RGBA8.

Nearest-neighbor sample (Phase 1).

Support scale + translation from BaseProps.transform.

Out of bounds → transparent.

#[wasm_bindgen]
impl Renderer {
    #[wasm_bindgen(constructor)]
    pub fn new(width: u32, height: u32) -> Renderer {
        utils::set_panic_hook(); // if desired
        let comp = Comp {
            width, height,
            background: [0,0,0,0],
            layers: Vec::new(),
        };
        let frame = vec![0; (width * height * 4) as usize];
        Renderer { comp, frame }
    }

    /// Replace the current comp with JSON description produced in JS.
    pub fn load_comp(&mut self, json: &str) -> Result<(), JsValue> {
        self.comp = serde_json::from_str(json)
            .map_err(|e| JsValue::from_str(&format!("comp parse error: {e}")))?;
        // resize buffer if needed
        let needed = (self.comp.width * self.comp.height * 4) as usize;
        if self.frame.len() != needed { self.frame = vec![0; needed]; }
        Ok(())
    }

        // parse Vec<Layer> and patch by id
        // implement minimal patch; ignore missing
        Ok(())
    }

    /// Render one frame at time t_ms; returns pointer to RGBA buffer.
    pub fn render(&mut self, t_ms: f32) -> *const u8 {
        self.comp.render(t_ms, &mut self.frame);
        self.frame.as_ptr()
    }

    pub fn frame_len(&self) -> usize { self.frame.len() }

    /// Optionally safe copy (slow)
    pub fn get_frame(&self) -> js_sys::Uint8Array {
        unsafe { js_sys::Uint8Array::view(&self.frame) }
    }

Load WASM bundle (async).

Build a Comp JSON snapshot each frame or only when structure changes (better).

After Rust render() call, copy returned memory into an ImageData and paint.

Avoid per-pixel Vec push; index directly into slice.

Convert u8→f32 only when needed; precompute opacity scalar.

Consider iterating as for chunk in out.chunks_exact_mut(4) { ... }.

Optimization is optional Phase 2; correctness first.
